# AI POWER - 企业AI赋能平台官网

企业 AI 解决方案平台官网，纯静态 HTML 实现，可直接部署到 GitHub Pages。

## 项目简介

AI POWER 是一个面向企业的 AI 赋能平台官网，展示企业 AI 解决方案、行业场景、成功案例等内容。网站采用深色科技风格设计，包含完整的页面模块和交互动效。

## 页面模块

1. **顶部导航栏** - Logo、导航菜单、预约咨询按钮
2. **Hero 首屏** - 主标题、副标题、CTA 按钮、AI AGENT 可视化图示、客户 Logo 墙
3. **企业 AI 痛点** - 4 张痛点卡片（工具碎片化、数据不可用、未进 Workflow、无法规模化）
4. **服务流程** - 6 步方法论（AI诊断→场景规划→方案设计→系统构建→落地实施→持续优化）
5. **解决方案** - 6 大方案卡片（智能办公、销售增长、企业知识库、Workflow、Agent、管理决策）
6. **行业场景** - 6 个行业卡片（制造业、零售电商、金融服务、专业服务、人力资源、企业运营）
7. **成功案例** - 案例展示 + 数据指标 + 视频占位
8. **合作伙伴** - 技术伙伴 Logo 展示
9. **CTA 行动区** - 预约免费诊断
10. **页脚** - 品牌信息、链接列、联系方式、社交媒体

## 技术栈

- **HTML5** - 语义化标签
- **Tailwind CSS** - 通过 CDN 引入，原子化 CSS 框架
- **原生 JavaScript** - 滚动动画、轮播指示器、平滑滚动
- **内联 SVG** - 所有图标均为内联 SVG，无外部图片依赖
- **Google Fonts** - Inter + Noto Sans SC 字体

## 特性

- 零构建，纯静态，开箱即用
- 响应式设计，适配桌面端、平板和移动端
- 滚动渐入动画
- 行业场景模块移动端横向滚动 + 轮播指示器
- 导航栏滚动背景变化
- 卡片 hover 动效
- AI AGENT 拓扑图呼吸光效动画

## 部署

### GitHub Pages

1. 将本仓库推送到 GitHub
2. 在仓库 Settings → Pages 中选择 `main` 分支作为发布源
3. 访问 `https://<your-username>.github.io/ai-power-website/`

### 本地预览

直接用浏览器打开 `index.html` 即可。

## 项目结构

```
ai-power-website/
├── index.html    # 主页面（包含内联 CSS 和 JS）
└── README.md     # 项目说明
```

## 注意事项

- 网站中的客户 Logo、合作伙伴 Logo、案例数据等均为占位内容，上线前需替换为真实信息
- "预约咨询"、"了解更多"等按钮目前为空链接，需配置实际跳转地址
- 字体通过 CDN 加载，离线环境下可能无法正常显示
